  1. N-Ary Tree (backend/dsa/n_ary_tree.py):
  2. Models the organization hierarchy: Workspace $\rightarrow$ Projects $\rightarrow$ Folders $\rightarrow$ Lists $\rightarrow$ Tasks $\rightarrow$ Subtasks.

  4. Trie Engine (backend/dsa/trie.py):
  5. Powers the Global Search Modal (Ctrl + K).
  6. Real-time prefix autocomplete across Tasks, Projects, Users, and Tags in $O(L)$ time (where $L$ is query length).
  7. Custom Hash Map (backend/dsa/hash_map.py):
  8. Separate chaining collision resolution with dynamic rehashing (load factor $> 0.75$).
  9. Used for high-frequency in-memory workspace permissions and member lookup caching.

  13. Thread-safe bounded buffer decoupling live workspace events (audit logs, emails, in-app alerts) from request threads.

  15. Directed Acyclic Graph with cycle detection.
